# Mapa funcional TEP

- Vista general: actividad, pendientes PERT, distribución A-E e indicadores clave.
- Casos: registro longitudinal desde sospecha hasta cierre.
- Ruta diagnóstica: mapa visual de apoyo.
- Programa y PERT: recursos institucionales compartidos y filtrados por TEP.
- Calidad y mejora: estándares, elementos, evidencias, hallazgos y acciones existentes.
- Indicadores: proceso, tiempos, seguridad, resultados y seguimiento.
- Ficha técnica: definiciones versionadas de los indicadores.

Terapias avanzadas, seguimiento y CTEPD se gestionan dentro de cada caso para conservar una sola historia trazable.
