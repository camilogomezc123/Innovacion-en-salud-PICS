# Diccionario de indicadores TEP

| Clave | Indicador | Denominador operativo inicial |
|---|---|---|
| `pretest_documented_pct` | Probabilidad pretest documentada | Casos válidos |
| `category_documented_pct` | Categoría A-E, fecha y justificación | TEP confirmados |
| `pert_activation_pct` | Activación o razón documentada | Confirmados C-E |
| `anticoagulation_documented_pct` | Inicio o contraindicación | TEP confirmados |
| `early_followup_pct` | Contacto logrado a 7 o 30 días | Egresados vivos |
| `followup_3m_pct` | Contacto logrado a tres meses | Egresados vivos |
| `hospital_mortality_pct` | Mortalidad hospitalaria | TEP confirmados |
| `persistent_symptoms_pct` | Disnea persistente o evaluación CTEPD positiva | Egresados vivos |

Las fichas técnicas institucionales permiten completar exclusiones, validación, responsables y versionado.
