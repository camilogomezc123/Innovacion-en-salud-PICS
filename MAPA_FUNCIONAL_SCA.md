# Mapa funcional SCA

## Flujo general

Síntomas → primer contacto médico → ECG → clasificación STEMI/NSTE-ACS → tratamiento documentado → reperfusión/estrategia invasiva → hospitalización → egreso → rehabilitación → seguimiento.

## STEMI

Inicio de síntomas → FMC → ECG ≤10 min → diagnóstico → activación Código Infarto → hemodinamia → primer dispositivo → vigilancia de complicaciones → auditoría obligatoria.

La medición diferencia ingreso directo (90 min) y traslado (120 min). La fibrinólisis y PCI de rescate se registran, pero nunca se ordenan automáticamente.

## NSTE-ACS/NSTEMI

ECG inicial/seriado → troponina → clasificación de riesgo documentada → estrategia inmediata, temprana, durante hospitalización, selectiva o conservadora → angiografía/revascularización → egreso.

## Auditoría y mejora

Caso priorizado → auditoría clínica → criterios cumplidos/no cumplidos → barreras y causa probable → hallazgo → 5 Porqués → causa raíz → PHVA → evidencia → verificación de efectividad.

## Egreso y rehabilitación

Checklist de egreso → conciliación y prevención secundaria → educación/teach-back → citas → remisión a rehabilitación → contacto → inicio → seguimiento.
